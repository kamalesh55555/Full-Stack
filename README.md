# 🎓 PeerLearn — Peer-Powered Academic Platform

> **Learn from your peers. Share what you know.**  
> A full-stack, curriculum-mapped learning platform designed for university students to collaborate, exchange quality notes and previous year question papers (PYQs), and host peer study sessions.

---

### 🚀 Key Features
- **Curriculum Hierarchy:** Navigate seamlessly: `University ➔ Course ➔ Semester ➔ Subject`.
- **Resource Hub:** Upload, download, upvote, and report notes/PYQs (PDF/PPT).
- **Peer Mentoring:** Schedule and join live peer study sessions via Google Meet.
- **Authentication:** Secure Email/Password JWT auth + Google One-Tap Sign-In.
- **Customizable UI (PeerV4):** Instant theme switcher (Light, Dark, Ocean Blue, Sunset Glow), dynamic typography (Serif, Sans, Mono), and bilingual support (English & தமிழ்).

### 🛠️ Tech Stack
- **Frontend:** React 19, Vite, Tailwind CSS, Lucide Icons, React Router v7
- **Backend:** Node.js, Express, Prisma ORM, Multer
- **Database:** PostgreSQL
